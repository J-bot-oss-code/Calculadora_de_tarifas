# ShipRateCalculator.Domain — Entidades compartidas

Class Library (.NET 8), sin dependencias de ningún otro proyecto.

Responsabilidad: definir las entidades y modelos que usan tanto la capa de
negocio como la de datos (por ejemplo `CountryRate`), evitando que ambas
capas dependan una de la otra directamente.

Se crea desde Visual Studio como proyecto **Class Library**, apuntando a
**.NET 8**, dentro de esta carpeta.
