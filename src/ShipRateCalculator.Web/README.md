# ShipRateCalculator.Web — Capa de presentación

Proyecto ASP.NET Core (Web App / MVC) con vistas en HTML + CSS.

Responsabilidad: capturar el peso y el país de destino ingresados por el
cliente, invocar a la capa de negocio y mostrar el resultado. No contiene
reglas de cálculo ni acceso a datos.

Se crea desde Visual Studio como proyecto **ASP.NET Core Web App (Model-View-Controller)**,
apuntando a **.NET 8**, dentro de esta carpeta.
